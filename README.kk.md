# Қазақша аниме субтитрлері

Мұрағатта 1 400 каталог жазбасы және 9 819 субтитр трегі бар. Автоматты құрылымдық тексеруден кейін 9 788 трек пайдалануға жарамды; 31 тректің уақыт белгілері мен мазмұнын түзету қажет.

Бұл сандар толық аударылған сериалдар санын білдірмейді. Аударма сапасы, бөлімдердің нөмірлері және метадеректер адамның тексеруін қажет етеді. GitHub Pages SRT және VTT форматтарын береді; ASS толық жергілікті құрастыруда қолжетімді.
