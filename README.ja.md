# カザフ語アニメ字幕

アーカイブには1,400件のカタログ項目と9,819トラックがあります。自動的な構造検査と形式修復後、9,788トラックが利用可能です。31トラックは時刻や内容の修復が必要です。

これらの数は翻訳完了作品数を保証しません。翻訳精度、話数番号、メタデータには人による確認が必要です。GitHub PagesではSRTとVTTを公開し、ASSは完全なセルフホスト用ビルドで利用できます。
